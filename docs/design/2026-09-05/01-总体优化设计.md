# 汽车电工电子互动游戏：总体优化设计

版本：1.0；审查开始：2026-09-05；设计完成：2026-09-06；用途：总设计与 Gemini 分阶段实施依据。

用户已确定：课堂教学为主，课后可以复练；Gemini 每完成一个开发阶段，由用户通知 Codex 检查。本文为设计交付，不代表软件已经实现或通过上线验收。

## 1. 总设计结论

保留“教材决定学什么，游戏重新组织怎么学”。进一步把产品定义为：**学生在汽车电工电子实训中心，通过完成工单、操作实验、解释证据、迁移排故，逐步获得独立解决基础电路问题的能力。**

有三条可选路线：

| 路线 | 长处 | 代价与问题 | 决策 |
|---|---|---|---|
| 教材任务依次包装成关卡 | 覆盖容易检查 | 容易变成目录加剧情，复杂任务仍挤在一关 | 不采用 |
| 完全自由的维修沙盒 | 自由度高，接近自主诊断 | 新手无从下手；仿真和内容验证成本过高 | 留作进阶练习 |
| 成长主线＋受控实验台＋阶段综合工单 | 有明确方向，也允许探索和多种正确路径 | 需要能力先修、统一仿真、证据评价 | 采用 |

产品名称宜使用“汽车电工电子”，不把全部课程强行解释成纯电动汽车维修。教材包含起动机、交流发电机、点火线圈；这些在传统汽车或混合动力情境中有位置，但不能冒充纯电动车必备结构。场景明确标注“通用低压电路／传统汽车／新能源汽车拓展”。新能源汽车高压维修、CAN、逆变器控制和 PWM 不替代本课程基础目标。

## 4. 学生的成长路线

课程分为六个篇章，加一个短序章。下列ID是新课程内部稳定标识，与开发阶段号、教材任务号分开；界面显示中文工单名称。

| 篇章 | 学生在做什么 | 主关卡与先后关系 | 篇章通行证据 |
|---|---|---|---|
| 序章：来到实训中心 | 熟悉工单、对象和求助 | O00维修中心第一天 → O01安全作业与应急判断 | 会看任务、操作、求助；在陌生工位辨认危险并选择安全处置 |
| 一：把电路看明白 | 接线、测量、寻找差异 | A01点亮检修灯 → A02给电路做体检 → A03元件身份核验 → A04电流到底走哪里 | 独立完成闭合回路、搭铁解释和三种基本测量 |
| 二：让电路按要求工作 | 做控制变量实验，完成改装要求 | B01找出变化规律 → B02灯组改装 → B03追踪节点与回路 → B04工位用电预算 → B05电源为什么带不动 → B06传感器信号与分压 | 对更换参数的电路作出预测、测量并解释；识别方案适用边界 |
| 三：凭证据找故障 | 同一症状提出不同假设 | C01越来越暗的灯 → C02同样不亮，原因不同 → C03第一次独立交车 | 故障定位、修复前后测量和解释形成闭环 |
| 四：让电和磁配合工作 | 控制继电器、观察运动和感应 | D01小开关控制工作灯 → D02让电机转起来 → D03转动为什么能发电 → D04断开开关后的现象 → D05变压器实验室 | 区分电流产生磁场、受力运动、电磁感应；完成相应接线和功能说明 |
| 五：让电路感知、判断和执行 | 认识电子器件，组合低压控制模块 | E01电流的单向通道 → E02断电后为何还有电 → E03从交流到直流 → E04小信号控制负载 → E05电路的条件判断 → E06转速信号寻踪 → E07装配一块训练板 | 能测器件、解释输入到输出、识别装配问题；焊接手艺另由教师实物确认 |
| 六：完成综合交付 | 承接完整但受限的综合工单 | F01实训中心交付挑战 | 在新情境中完成安全、测量、解释、诊断、功能复检，并提交个人答辩 |

这不是28次十几分钟就能学完整门课。每个主关可拆成2—4个10—20分钟游戏片段；复杂关跨多次课堂。时长是试教假设，须用学生数据调整。教材目标保留，重复演示可压缩，必要的实物训练不能被游戏时长吞掉。

### 4.1 先修关系与支架

推荐顺序按上表执行，但引擎不依赖数字大小解锁：

- A02先教电压挡、COM/VΩ插孔、两点测量；A03教断电隔离后测阻；A04才教电流挡串入和钳形表。每次只增加一种关键仪表规则。
- B02先观察串并联现象，B03再用节点和回路测量解释KCL/KVL。避免先塞入抽象定律再允许接灯。
- B06完整学习传感器分压；A03只研究物理量与阻值的关系，不要求先理解ECU。
- D01可在B04之后作为教师安排的支线，不必等C03；默认主线先完成直流诊断闭环，防止追求“高级部件”冲淡基础。
- D03在D02之后提供交流和波形基础；D04依赖D03的感应概念；D05依赖D04。D05保留教材星号扩展属性，学校可设为选学，但不能自动标记已掌握。
- E01依赖B04，E02依赖A03、B01；E03同时依赖D03、E01、E02；E04依赖D01、E01、B06；E05依赖A02、B02，默认安排在E04后；E06依赖D03、E05；E07依赖拟装板所用器件关卡。
- F01依赖C03、E03、E04、E05、E07虚拟部分；题库若涉及电机或转速，还必须要求D02或E06。未学模块不得随机抽入。

安全门槛与普通前置分开。教师可以布置回看、补练或演示，不能把演示数据写成学生独立通过，也不能绕过危险操作拦截。

### 4.2 全课程反复出现的真实任务

以检修灯、灯组、传感器训练台、小电机、低压控制板为主要对象。第一次点亮灯建立闭合回路，第二次测量，第三次比较串并联，第四次分析压降，第五次接入继电器与控制信号。对象熟悉，问题升级，降低重新理解场景的负担。

每篇章末重新换对象或拓扑，不能始终只用同一盏灯。更换台灯为风扇时，要明确负载模型已变化，不能沿用纯电阻规律作全部推断。

## 5. 真正的游戏循环

标准工单循环：**接单 → 观察症状 → 提出预测或假设 → 选择工具和动作 → 看到物理结果 → 收集有效证据 → 调整方案 → 功能复检 → 说明理由 → 新情境迁移。**

概念探索关不强套“坏了就修”的剧情，用实验委托：“找出影响阻值的因素”“为两个灯设计互不影响的接法”。

每关必须有以下要素：

1. 有工作目的，学生知道“为什么做”。
2. 至少一个需要判断的选择，不能所有步骤都被箭头点名。
3. 操作改变真实模型状态，动画和读数由同一状态驱动。
4. 至少一种允许发生的非危险错误，如无效测点、接成断路、换错正常件；结果能促使学生修正。
5. 有可解释的完成条件，不仅是点过按钮。
6. 有至少一种变式，改变参数、故障位置或拓扑；改变物体颜色不算迁移。

### 5.1 成长和奖励

身份称号使用“见习学员、回路搭建能手、测量助手、诊断学员、控制电路学员”，明确是游戏成长称号。取消“技师资格认证”“符合教学大纲”等未经审定的保证性文案。

工具解锁与能力相连：会安全测压后开放节点测量；掌握支路电流后开放电流证据比较；能诊断后开放随机工单。徽章对应已提交的证据，经验值可表示参与，但不能补偿关键安全能力欠缺。

默认没有生命值、全班速度排行榜、失败清空或过长倒计时。标准诊断关可有虚拟工时/零件成本，作为复盘信息；安全合理求助不扣分，不奖励少求助导致冒险。动画、音效可关闭，不影响任务状态。

### 5.2 引导渐隐与失败恢复

| 模式 | 系统支持 | 记录解释 |
|---|---|---|
| 跟练 | 示范一次、提示区域、解释仪表选择 | 练习完成，不标独立掌握 |
| 独立练习 | 保留工单、对象标签、按需提示 | 关键操作自主完成且解释有效，可标独立完成 |
| 迁移 | 新参数/新故障/新布局，无测点高亮 | 满足独立条件后，标迁移完成 |

提示四级：追问观察 → 提醒原理 → 缩小操作范围 → 展示局部示范。查看帮助本身不减能力分；若系统给出了该能力的关键解法，该次不能证明独立，必须换一道等价题补证据。设备操作说明、无障碍帮助不算学科提示。

普通错误允许回退一步、拆线、复测或重开本次实验；不重置整门课程。危险请求先被拦截，显示原因与安全替代动作，再让学生重新决策。学习模式允许改正；独立考核出现关键危险请求时转为补练，本次不计独立安全达成。

## 6. 两个可直接实现的示范关

### 6.1 A03《元件身份核验》：下一批新增关的样板

前置：A01回路，A02仪表基础。新能力只引入电阻测量和标识解释。

工单：训练台送来三只外观相似元件，需找出符合标称与公差要求的电阻；后续检查一个可变电阻。环境是断电、隔离的低压训练台，数字表在桌面，默认未接笔。

片段一：学生读取色环或标识，先记录预测区间；配置指定220Ω±5%，正确区间209—231Ω。单位换算提供工具卡。数字表选择Ω挡、COM/VΩ插孔，连接元件两端，记录读数。错量程显示OL时可换量程，不能把OL一律解释为元件断路。

片段二：提供224Ω、330Ω、开路三只样件，实际读数由元件状态、测量条件和仪表量程生成。学生依据区间选择合格件，不能只点“正确颜色”。电阻标称功率另作铭牌识读，不从阻值推断功率。

片段三：旋转电位器；测两固定端、滑动端与固定端，记录至少三个位置的值，说明哪组变化。把电位器换成指定类型热敏或光敏元件，只作单变量观察；不同敏感元件不共用“温度越高阻值越低”的无条件结论。

迁移：换为另一组标称、公差、单位或接线布局，不提示正确插孔。证据是标称区间、仪表状态、测量条件、读数及选择解释。必须完成安全测阻与区间判断，不能用猜中合格件替代。色环全套读值和敏感元件系列可分后续片段，不在一个15分钟片段里全部强教。

### 6.2 C01《越来越暗的灯》：中期诊断标杆

工单：已知灯在训练台正常，装入教学线束后偏暗。学生可提出电源异常、供电接点异常、搭铁异常、负载异常等假设。系统不先标红故障点。

确定性基准：理想12V电源、6Ω等效电阻灯、供电侧0.5Ω附加电阻、搭铁侧0.1Ω附加电阻。预期I=12/6.6≈1.81818A，灯压约10.90909V，供电侧压降约0.90909V，搭铁侧约0.18182V。灯功率约19.83471W。这里只是标注清楚的纯电阻教学灯模型。

学生可以先测灯两端，也可以先对比供电侧与搭铁侧，只要测量有区分假设的作用就认可。空载/带载切换必须真的改变拓扑；断开负载后电流为0，不能让所有位置仍显示固定“故障压降”。悬空节点返回“不确定/无法据此判断”，不能伪造精确电位。

修复供电接点后，该侧电阻为0，回路总阻6.1Ω；I≈1.96721A、灯压≈11.80328V。学生须复测确认，说明剩余压降位置。任务参数卡明确修复验收范围，不能把示范数值包装成所有车型的通用阈值。带载压降诊断的专业背景可参考[福禄克技术说明](https://www.fluke.com/en/learn/blog/automotive/electrical-automotive-troubleshooting)。

至少三种种子：供电接点高阻、搭铁高阻、负载开路。初学只开放第一种；迁移才更换，且必须有足够测点可区分。未完成测量的结论可以提交但显示“证据不足”，不得直接揭晓故障。无依据换灯允许执行，故障仍在，复盘展示成本。

## 7. 课堂如何使用

按45分钟一课时给出可调整样例：5分钟工单与预测、15分钟游戏操作、8分钟比较证据、12分钟对应实物或第二个变式、5分钟退出条与保存确认。学校课时长度不同，按比例调整；综合工单和焊接使用连续课时。

教师课前选择关卡、模式、截止时间、允许工具与对应实物任务；课中只看需要介入的信号：反复危险尝试、长时间无有效动作、同一错误重复、提交未同步。学生可主动举手。阈值首次试教暂用“3分钟无有效动作／同一误区连续3次”，只是提示教师查看，不自动判低能力。

两人一机时可设操作员和记录员，片段后交换；共用成果只计小组活动，个人达成要各自完成短迁移题或教师口头/实物观察。不得把同一份小组游戏记录复制成两人的独立掌握。

课后复练使用同能力不同种子；第二天课堂用3—5分钟检索和测量小任务复核，防止“昨晚看提示过关，今天不会操作”。这是形成性复核安排，不需自动推送打卡。

## 8. 评价：从分数变成可信证据

全课程统一六维：安全规范、电路识读、工具测量、规律解释、诊断策略、证据表达。每项状态为“尚无证据／跟练完成／独立完成／迁移完成”，实物表现单独记录“待观察／需练习／教师确认”。没有观测不能默认满星或最低一星。

关卡完成条件：所需产物有效＋功能复检通过。独立达成条件：该能力关键动作不依赖解法提示＋关键安全规则通过＋解释能引用本次证据。迁移达成条件：在不同情境下再次满足独立条件。每关规则配置列出具体必需证据，不能只写“理解原理”。

计算属于明确教材目标，必须保留适量预测、单位换算和计算证据；可以提供计算器，不能以“不是答题游戏”为由删掉计算。反之，纯计算得分也不能替代接法和诊断。

保留历史总分作旧版本记录，新版默认不用平均星级支配解锁。若学校需要学业分数，由教师制定有版本的量规，安全关键项不可由其他高分抵消；游戏形成性结果与实物技能结果分别呈现。

重复练习保留首次、最近一次、最佳独立、迁移记录，注明版本和提示层级。后一次失败不抹除旧证据，也不能隐瞒当前困难。升级后旧成绩标“旧版完成，尚未按新版复核”，尤其旧安全关不得直接变成新版安全掌握。

共同授课建议规则：已发布的课程评价由当前合法任课教师共享阅读，显示作者；只能作者修改自己的评价并留修订记录，其他教师可追加意见。草稿仅作者可见；撤销任教后立即撤销访问。此为本设计确定的拟实施规则，尚需实施与验收，不能把当前私有评价称为既有共享功能。

## 9. 技术设计与演进边界

### 9.1 保留并分层

保留React/TypeScript、现有服务端认证和SQLite、三角色、班级关系、课程入口及已可用的SVG对象。不要为此次课程设计改框架、重做账号或开发3D。

| 层 | 责任 | 不得承担 |
|---|---|---|
| 课程注册表 | 关卡、目标、先修、发布状态、版本、模型依赖 | 直接存学生成绩 |
| 场景/工单配置 | 元件、初态、故障、提示、量规、证据需求 | 每个测点的硬编码正确答案 |
| 物理与仪表模型 | 由拓扑、参数、状态和工具计算结果 | 按剧情强行点亮负载 |
| 安全规则 | 动作执行前决定允许/拒绝及解释 | 由按钮自行绕过 |
| 学习与事件层 | 尝试、证据、提示、状态迁移、量规计算 | 相信客户端自报100分 |
| 视图与导师层 | 渲染现象、接收意图、给分级提示 | 改变物理结果或自行判分 |

动作链：学生意图 → 安全检查 → 合法状态变更 → 仿真求值 → 仪表读数/画面反馈 → 语义事件 → 证据投影。被拒动作只记录拒绝和原因，不改变危险状态。

课程表至少有 `levelId,title,chapterId,objectiveIds,prerequisiteCapabilities,requiredModels,publicationStatus,contentVersion,rubricVersion`。发布状态与学生学习状态分离：尚未发布的关卡显示“建设中”，不能因前置满足就显示“可实训”。前后端共享同一份已验证注册数据，禁止重复维护两套顺序。

### 9.2 物理模型按阶段扩展

第一层：复用拓扑分析，增加限域直流电阻网络求解、测量加载和故障状态。求解器输出节点电位、支路电流、元件功率；通过独立算例验证。短路、开路、悬空、不支持模型、求解失败要明确区分，不能一律读数0。

第二层：加入RC/RL时间响应、继电器和电机的可解释简化模型、交流波形与仪表有效值能力。不支持的波形或模型应禁用相应任务。RC预置电路可用解析解；不要求一步完成任意电路瞬态求解器。

第三层：二极管分段模型、三极管工作状态、逻辑门、整流滤波受控电路族。声明适用范围；不能把二极管恒定0.7V、所有三极管固定倍数放大、所有钳形表能测直流当成普遍事实。

万用表模型明确：型号/能力配置、量程、分辨率、内阻、插孔、挡位、保险状态、表笔测点。测阻须断电并考虑储能与并联支路；测流改变被测网络；电压表接在两点之间。通断蜂鸣阈值来自仪表配置，不等价于“好线束”；电容挡、二极管挡按模型支持逐步开放。[福禄克连续性测量说明](https://www.fluke.com/en-ca/learn/blog/digital-multimeters/how-to-perform-automotive-continuity-checks-with-a-multimeter)可作工具规则参考。

短路危险请求在学生操作层拦截；预置故障可以由情境引擎加载并呈现已熔断状态。需要展示熔断动态时使用有来源的简化时间-电流模型，不以I大于额定值一瞬间就必熔断代替实际特性。热效应若没有环境、散热参数，只显示趋势和相对风险，不编造精确温度。

### 9.3 学习数据

沿用用户、班级、任教关系、课程版本、尝试和事件表，增加或迁移以下语义，不另建平行账号系统：

- 尝试：`attemptId,studentId,classIdAtStart,courseVersion,levelId,mode,seed,modelVersion,rubricVersion,status`。
- 事件：`eventId,attemptId,sequence,actionType,payload,clientTime,receivedAt`；记录工具配置、测点、有效测量、假设、提示层级、修复和复检。无需采集每帧动画和每次鼠标移动。
- 证据：目标ID、源事件、达成层级、判定规则版本、教师实物观察。
- 任务布置：班级、关卡/能力目标、模式、允许工具、有效期；服务端授权。

开局由服务端分配attempt与seed，固定版本。新复练产生新attempt；关闭一个attempt不能把关卡永久锁成不可复练。事件以attempt内序号排序，幂等ID和内容一致性校验；刷新后从已确认检查点续做。断网时显示本账号待同步队列，重连幂等上传；切换账号隔离队列和异步响应，不能把甲的数据交给乙。

独立/迁移达成由服务端根据事件和固定模型/量规重算；客户端可以即时反馈，不能最终裁定。第一版仍是课堂形成性评价系统，不宣称防作弊考试平台。旧服务端已有权限、范围和顺序校验须保持。

### 9.4 迁移现有进度

现有LEVEL_00→O00，LEVEL_01→O01，LEVEL_02→A01；保留旧尝试、原分数和原版本。旧完成只展示旧版完成，按新版能力差异安排简短复核。未实现LEVEL_03—09不据名字强行转换能力，标记为旧计划项，替换展示但保留可能存在的历史记录。

迁移先导出测试快照，在独立数据库验证；数据库备份必须使用已提供的SQLite一致性备份流程，不只复制一个可能仍在写的app.db文件。建立可逆映射、迁移版本和回滚步骤，不删除真实学生成绩。客户端缓存发现旧版时由服务端迁移结果替换，不能用本地旧地图覆盖。

## 10. 安全教学的强制修订

O01拆为“日常工位准入、触电/应急情境、电气火情判断”三个短片段，允许课堂分段。安全规则贯穿所有关卡，后续出现电容、感性元件、焊接时补充储能和热风险。

触电原理用抽象等效模型、预录案例或“标出危险路径”呈现，学生角色没有“试着碰一下”的任务。绝缘防护展示选用、检查和限制，不能得出穿戴后可主动接触带电部分。国际工作实践资料可辅助检查这种误导，但不代替学校适用标准与设备规程：[OSHA电气工作实践](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.333)。

“急停已按下／指示灯熄灭”不自动等于“所有危险源已隔离”。场景明确电源类型、隔离方式、是否有储能和需要的确认步骤。初学者遇到超出训练权限的危险，正确行为可以是隔离区域、求助和等待专业处置。

急救内容建立来源、适用对象、复核人、日期、版本和发布状态。当前`firstAidConfig.json`仍标待专业复核，不能因为填了参数就算完成。依据现行[AHA成人基础生命支持指南](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/adult-basic-life-support)核对识别、呼救、AED与按压相关内容，再由学校专业人员审定中文表达与实训流程；不把具体操作位置争议简化为字符串替换。网页节奏练习不能证明按压深度、回弹或人工呼吸合格。

电气火情允许“无法安全处理，立即撤离报警”成为正确结局；不能强迫所有情境拿灭火器完成通关。灭火设备选择、适用条件等由审定规则配置，不能让语言模型临场生成。

焊接游戏训练工艺判断、元件布局和质量辨认；实物焊接的温度、材料、时间以学校设备与工艺卡为准。虚拟完成不得自动变成手工焊接技能合格。

## 11. 界面和可用性

界面优先级：当前工单一句话 → 中央可操作工位 → 工具状态 → 最近反馈 → 证据抽屉。导师默认折叠，原理图与实物可切换/联动；不同时堆放雷达图、大段知识、工单和多级工具栏。

正式主操作支持1366×768桌面和1024×768横屏；按钮/端子命中区按44×44 CSS像素设计，缩放后仍检查命中区。鼠标、触摸、键盘均可完成接线，可用端子列表作为等效入口。关键文字默认16px、标签14px；尺寸是设计要求，仍需实机检查。

手机首先支持看工单、知识卡和报告；复杂接线未适配前明确推荐横屏或更大设备，不展示不可操作画布。动画减少与静音不影响读数和判定。显示保存中/已保存/待同步/失败重试；关卡完成与服务器保存成功分别表达。

## 12. 何时才算成功

先完整交付O00—C03直流基础与诊断闭环，再扩展D/E/F；不要一次生成全部关卡空壳。后半程目标已纳入本设计，不等于允许未经页级核对直接发布。

技术通过、教学通过、实机部署通过三张清单分别签字。首轮3—5名未用过系统的学生零说明试玩，检查能否找到任务、完成一次测量、解释读数；随后一班试教，关注帮助后是否真能独立迁移，而不是单看完成率。记录样本、设备、时间和失败点，不预先承诺学习效果提高百分比。
