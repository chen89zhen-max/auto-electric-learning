## 打开与操作

本地开发服务：`npm run dev -- --port 3010`，打开 http://localhost:3010/workshop-preview 。该路由是无账号、无成绩写入的公开视觉样板，仅运行本地状态。刷新/重新体验会重置样板，不删除正式学习进度。

原“维修中心第一天”的WELCOME阶段默认进入样板；右上角“原入职训练”可回原流程。其他关卡、认证和数据库逻辑未改。实际新增路由在部署后同样可访问，但没有学生数据或管理功能。

点击工位标记或下方快捷按钮，学生走到对应位置后出现对话。点击前方地面自由行走；地面按钮获得键盘焦点后可用方向键移动。点击陈师傅会走近交谈。师傅在关键步骤后走到下一工位等待。

体验顺序：工单台领取工单→工具柜取无源训练连接件→观察车辆及举升机工位→实训台关电源→器材归位。未满足先修步骤时不提供跳步完成动作。

## 设计与范围

- 固定视角2.5D环境：有材质、光照和空间透视的车间背景，包含银色车辆、双柱举升机、工具柜、工单终端和电子实训台。
- 前景可移动人物：SVG绘制师生，工装区别身份，步行动画、朝向、影子、姓名标记；角色在前方通道活动，不穿车。
- 动态物体状态：领取后显示手持连接件；归位后移到台面；练习台指示灯随电源状态改变。
- 宽屏右侧对话，较窄屏幕下方对话；键盘可通过工位按钮完成流程。手机小屏使用可横向滚动的场景，不声称已完成手机沉浸适配。
- 无LLM、无外部运行API、无WebGL或新依赖。人物和道具动作来自状态，不是生成图片中的静态人物。
- 边界：车辆、举升机、柜体目前是背景，不支持开车门、升降、逐抽屉操作；人物是2D动画，不是可旋转3D模型。师傅按脚本带路，不做自主AI寻路。该范围用于确认美术和交互方向。
