版本1.0；完成日期2026-09-06。与《01-总体优化设计》《03-Gemini执行任务书》共同使用。

## 使用口径

这是目标级设计覆盖，不是已实现覆盖，也不是整本教材逐页审定报告。任务2—9依据前次完整课程地图；任务10—19依据本次直接核对的各PDF第1页任务目标，页内其他实验和参数在相应开发阶段补审。教材共243页。下表“来源页”一律为PDF文件页序，避免与印刷页码混淆。

目标ID中T表示教材任务；关卡ID使用总体设计中的O/A/B/C/D/E/F编号。游戏关卡可以跨教材任务，同一目标可以多次练习。仅显示知识卡不算技能覆盖；操作技能必须有行为证据。

## 防遗漏的具体处理

- **模拟表与钳形表不能直接删掉。** 前次地图建议作为拓展，是降低新手负荷的安排；本设计将其安排在数字表熟练后的独立短任务。若学校决定不教某项目，覆盖矩阵应显式标“本轮未覆盖”并说明教学安排，不能继续声称覆盖教材全部目标。
- **力敏电阻、霍尔与磁电转速传感器必须各有位置。** 不把热敏传感器一个演示泛称为完成传感器教学。案例标明器件原理，不把所有汽车压力传感器都称为电阻式。
- **分压与分流不是任意设备的供电方案。** B06要让学生看到负载接入后的分压改变；仪表扩程限于明确参数的教学模型。真实汽车电源改装需按设备要求，游戏不能教“串个电阻就能给任何低压设备供电”。
- **交流、感应、整流、滤波分步学。** D03的交流基础不能等到E03整流才突然出现；E03依赖E01、E02，滤波结果不能早于电容原理。
- **焊接早期可做工具和质量观察。** E07完整装配等到相关器件已学；无需等到学完全部课程才首次认识烙铁，但实物使用须由教师组织。
- **数学表达不丢。** 单位、公差、U/I/R、功率、电能、串并联计算与图表解释纳入行为证据；支持计算器和单位卡，不要求用心算速度证明电路能力。

## 进入实现前的目标卡格式

每个目标组拆成可追踪的目标卡，例如`T08-S02`（技能目标），至少填写：

| 字段 | 要求与示例 |
|---|---|
| 来源 | 文件名＋PDF页序＋印刷页码（可辨认时）＋原目标/图号；不能猜页码 |
| 目标 | “在规定带载条件下，用电压挡跨接连接点两端并记录压降” |
| 条件 | 仪表型号配置、供电状态、负载状态、允许工具、模型版本 |
| 动作与产物 | 配表、选测点、读数；形成带测点和状态的测量记录 |
| 误区 | 只量对地电压、空载结论、把压降与电源电压混淆 |
| 通过规则 | 合法测量＋记录有效＋能说明这次测量排除了什么假设 |
| 迁移 | 换接点、阻值或回路布局，禁止同一答案位置不变 |
| 仿真边界 | 所用器件、数值模型、误差范围、未支持情况 |
| 状态 | 规划／原文核对／专业复核／已实现／教学验收；分别记录，不能合并 |
