## 2. 核心教学与设计规范贯彻

依照《TRAINING_DEVELOPMENT_STANDARDS.md》严格执行五大设计红线：
1. **彻底杜绝“剧透”预选（Zero Spoiler）**：
   - E01~E07 全部关卡在初始加载时，选项卡状态统一为 `null`，边框统一为中性灰 `border-slate-800`，未提交前严禁高亮正确答案或将 A 选项标绿。
   - 必须在学员主动选择并点击“提交判定”后，才显示答案解析与对比提示。
2. **五阶段渐进式黄金实训流（5-Stage Progressive Training Flow）**：
   - 所有 E01~E07 关卡严格遵循五阶段渐进流：
     1. 阶段 1：原理认知与现象辨析
     2. 阶段 2：规范接入与仪器测试（万用表二极管档/hFE档/试验箱/示波器/恒温烙铁）
     3. 阶段 3：定量物理规律与工程设计计算（限流阻值/RC时间常数/整流纹波/饱和偏置/联锁真值表/频率气隙/IPC焊点标准）
     4. 阶段 4：独立盲测排故实战（4 类随机/打乱未知器件与故障诊断）
     5. 阶段 5：实车工程修复与交车工单闭环（整车系统排故、元器件更换与长时路试/量规验收）
3. **大视效容器与工业级 UI**：
   - 实训主容器采用 `flex-1 min-h-[580px]` 撑满视口，SVG 画布高度设为 `h-60 lg:h-64`，动态动画包括：二极管 PN 结电场、电容器充放电曲线示波器、桥式整流波形正负半周翻折、三极管输出特性曲线工作点移动、数字逻辑芯片真值表动态触发、发动机靶轮旋转与双通道波形、显微镜下 IPC 焊点形态切片。
   - 仪表读数与示波器波形大字体呈现，兼具学术严谨与实操沉浸感。
4. **万用表与仪器防呆保护**：
   - 万用表面板默认初始状态为 `OFF`（显示 `POWER OFF` / `----`），未旋至对应档位（如二极管档、hFE档、直流电压档）直接测量将触发蜂鸣拦截与警示。
5. **陈师傅导师语音合成（Web Speech TTS）**：
   - 每个阶段陈师傅台词更新时，自动调用原生 Web Speech API 朗读，卡片右上角常驻喇叭按钮支持随时重播。
