# P3 交接：直流规律与设计（B01—B06）

## 已交付内容

- B01：固定电阻变电压、固定电压变电阻、未知电阻预测；明确控制变量，阻止“电阻随电压变大”的错误归因。
- B02：双灯串联/并联的 MNA 对比、拆除单灯后的独立性与节点判定反例。
- B03：KCL、KVL 和两次参考地求解，展示绝对电位变化而两点电压差保持不变。
- B04：实际/额定功率、8 小时电费、14A 对 10A 熔丝的保护拦截。
- B05：蓄电池空载、轻载、重载曲线，重载内阻压降导致端电压塌陷的诊断。
- B06：NTC 水温分压、ECU 高阻采样和错误低阻负载造成的 V09 分压失真。

## 集成方式

- `src/levels/b01` 至 `b06` 均采用 Experience + Scene，Scene 的数据由 `DCSolver` 或 `DCAnalysisUtils` 计算。
- `src/courses/registry.ts` 已将 B01—B06 发布为 `1.0.0`，课程大厅改从规范注册表生成课程卡片。
- `GameShell` 支持大厅导航及 `?level=B01` 至 `?level=B06` 直接访问；未发布关卡不从 URL 放行。
- 完成组件将关卡声明的六维证据和练习模式直接写入独立 attempt，避免原有嵌套证据无法被服务端识别的问题。

## 回归重点

1. 直接打开 `?level=B04`，检查工位预算交互和回到大厅的地址恢复。
2. 完成 B01 后重复以“独立/迁移”模式进入，确认 recent/best attempt 和 `RULE_EXPLANATION`、`TOOL_MEASUREMENT` 证据更新。
3. 后续若重做进度解锁模型，应将 B01—B06 的先修链同时映射到旧版 `LEVEL_*` 进度迁移策略；当前规范课程大厅已按 canonical IDs 实时校验先修条件。
