## 2. 核心教学与设计规范贯彻

依照《TRAINING_DEVELOPMENT_STANDARDS.md》严格执行五大设计红线：
1. **彻底杜绝“剧透”预选**：
   - D01~D05 全部关卡在初始加载时，选项卡状态统一为 `null`，边框统一为中性灰 `border-slate-200`，未提交前严禁高亮正确答案或将 A 选项标绿。
   - 必须在学员主动选择并点击“提交判定”后，才显示答案解析与对比提示。
2. **五阶段渐进式黄金实训流**：
   - 所有 D01~D05 关卡严格遵循五阶段渐进流：
     1. 阶段 1：原理认知与现象辨析
     2. 阶段 2：规范接入与安全操作
     3. 阶段 3：物理规律与对比测试
     4. 阶段 4：独立盲测排故实战
     5. 阶段 5：实车工程修复与交车工单闭环
3. **大视效容器与工业级 UI**：
   - 实训主容器采用 `flex-1 min-h-[580px]` 撑满视口，SVG 画布高度设为 `h-60 lg:h-64`，动态动画包括：继电器电磁衔铁吸合、直流电机换向旋转、发电机定子磁场切割、点火线圈高压电弧跳火、变压器铁芯交变磁通。
   - 仪表读数与示波器波形大字体呈现，兼具学术严谨与实操沉浸感。
4. **万用表防呆与开机保护**：
   - 万用表面板默认初始状态为 `OFF`（显示 `POWER OFF` / `----`），未旋至正确挡位直接测量将触发蜂鸣拦截与警示。
5. **陈师傅导师语音合成（Web Speech TTS）**：
   - 每个阶段陈师傅台词更新时，自动调用原生 Web Speech API 朗读，卡片右上角常驻喇叭按钮支持随时重播。
